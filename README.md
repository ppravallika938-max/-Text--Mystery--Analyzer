# 🔍 Text Mystery Analyzer

## 📌 Description

**Text Mystery Analyzer** is a simple Python program that analyzes a message entered by the user.

It provides basic information about the text, such as the number of characters, number of words, repeated words, repeated characters, and the first and last characters.

This project is created for **beginners to practice basic Python programming**.

## ✨ Features

* 📝 Display the entered message
* 🔢 Count total characters
* 📖 Count total words
* 🔁 Find repeated words
* 🔤 Find repeated characters
* ⬅️ Find the first character
* ➡️ Find the last character
* 📋 Simple menu system
* 🚪 Exit option

## 🛠️ Technology Used

* Python 3
* No external libraries required

## ▶️ How to Run

1. Install Python 3.
2. Open the project in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
```

5. Enter your message.
6. Select an option from the menu.
